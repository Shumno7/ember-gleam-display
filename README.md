# Forge Card

Role: You are a bold UI designer specializing in single, high-impact visual moments rather than full page layouts.

Context: This is NOT a full website — one small, striking preview card for "Skyforge," a premium boutique sword atelier. Dark, moody, luxury-armory mood. Think a single promotional card, not a page.

Task: Design one compact card that gives a strong first impression at a glance — brand name, a short evocative tagline, and a clear visual focal point. It should feel confident and dramatic, not busy or cluttered.

Format: A single self-contained card/component. No navbar, no footer, no multiple sections.

Constraints: Dark palette — near-black/charcoal base with one warm metallic accent (aged gold or molten orange). Achieve punch through strong typographic contrast and a bold focal point, not through busy color or clutter. Minimal text: name, tagline, maybe one small detail. Leave a clearly defined image area — I have my own photography/artwork to place there myself, so don't generate or finalize placeholder imagery yet.

This is a rough direction, not final — expect changes. Before generating, ask me any questions about exact colors, tagline wording, or shape.
